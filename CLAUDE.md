# Finance Analyzer

A financial analysis app for students. Portfolio project. Full spec to come.

## Goals
- Help students understand their own finances.
- Clean, readable code worth showing in a portfolio.
- The owner is a beginner: learning matters as much as shipping.

## How to work
- **Explain the plan before writing code.** Say what you'll change and why, then wait for a go-ahead.
- **Keep changes small.** One idea per change, easy to review and understand.
- **Explain new concepts simply.** When a new tool, library, or idea comes up, give a short plain-English explanation. Suggest adding it to `LEARNING.md`.

## Setup
- Python 3.12, managed with `uv`. Code lives in `src/finance_analyzer/`.
- Run: `uv run finance-analyzer`
